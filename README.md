# Nolan Hughes — Hire Me (Modern)

Modern personal "Hire Me" site — Next.js App Router + Mantine + Framer Motion.

## Setup
```bash
pnpm i  # or npm i / yarn
pnpm dev
```

Edit these in `app/(site)/page.tsx`:
- `EMAIL`
- `CALENDLY` (optional)
- Put your headshot at `public/avatar.jpg` (or use `?img=<url>` query param)
- Repos are limited to `notesmith, absence-request, real-time-chat` (edit `SELECTED_REPOS` to change).

## Preview
- Use `?gh=nhugh406` to change GitHub user for testing.
- Use `?img=https://...` to override avatar temporarily.
